Why Use ReputeX?

🛡️

0–100 Explainable Risk Scoring

Evaluates wallet age, transaction volume, counterparty graph risk, scam database reports, and protocol safety to assign clear LOW, MEDIUM, HIGH, or CRITICAL risk ratings.

🔍

Multi-Chain Read-Only Scanner

Seamlessly scans web pages for Ethereum (EVM), Bitcoin (Bech32/Legacy), Solana (Base58), and ENS domain names without modifying page DOM or violating site CSP rules.

🏷️

Entity Classification Predictions

Predicts likely entity types with probability breakdowns: Exchange, Personal Wallet, Whale, Merchant, Bot, Mixer, or Possible Scam Wallet.

💬

Nemotron AI Chat Assistant

Ask natural questions like "Is this wallet safe?" or "Why should I trust this address?" inside the extension popup or floating hover overlay for human-like AI responses.

⚡

Public Vercel Serverless Backend

Anyone who downloads the extension can query your hosted Vercel API backend instantly without running local Node.js servers.

🔒

Manifest V3 & CSP Compliant
