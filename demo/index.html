Real-Time Web3 Wallet Reputation & Risk Assessment

ReputeX automatically scans web pages for crypto wallet addresses (Ethereum EVM, Bitcoin, Solana & ENS), calculates explainable trust scores, predicts entity classifications, and provides a live AI security assistant.

📥 Download Extension (GitHub) 🧪 Open Interactive Web Demo

Key Features

🛡️

0–100 Risk Scoring

Evaluates wallet age, transaction count, graph proximity risk, and blacklist reports for LOW, MEDIUM, HIGH, or CRITICAL risk ratings.

🔍

Multi-Chain Scanner

Scans web pages for Ethereum (EVM), Bitcoin (Bech32/Legacy), Solana (Base58), and ENS domain names safely without DOM modification.

🏷️

Entity Classification

Predicts entity type likelihoods: Exchange, Personal Wallet, Whale, Merchant, Bot, Mixer, or Possible Scam Wallet.

💬

Nemotron AI Chatbot

Ask natural questions like "Is this wallet safe?" inside the extension popup or floating hover card for real-time AI security answers.
